# VLoc 版本发布

版本号在 `app/build.gradle.kts` 中维护。每次发布递增 `versionCode`，`versionName` 使用 `X.Y.Z`。Git 标签和 GitHub Release 使用 `vX.Y.Z`。

## 构建和签名

使用 JDK 21、Android SDK Platform 36 和 Build Tools 35.0.0。运行：

```powershell
.\gradlew.bat :app:testDebugUnitTest :app:lintDebug :app:assembleRelease
```

Gradle 生成 `arm64-v8a` 和 `armeabi-v7a` 两个未签名包。分别使用同一把发布密钥签名。把密钥和密码保存在仓库之外并做好备份。后续覆盖更新需要使用同一签名。

```powershell
apksigner sign --ks <私有密钥库> --out <签名后的 APK> <未签名 APK>
```

将两个签名包交给发布脚本。脚本核对签名、版本和 ABI，生成下载文件与 `vloc-update.json`：

```powershell
python scripts/release_assets.py <ARM-v8-APK> <ARM-v7-APK> --sdk <SDK目录> --output dist/vX.Y.Z
```

后续发布时，每个上一个正式安装包都可以用一个 `--base <旧APK>` 参数传入。脚本只保留至少比完整包小 5% 的差分文件，并验证还原结果和新签名 APK 逐字节一致。

## GitHub

提交代码和更新记录，创建标签并推送后，把同一次构建生成的 APK、`vloc-update.json` 及差分文件一起上传。

```powershell
git tag -a vX.Y.Z -m "VLoc vX.Y.Z"
git push origin main vX.Y.Z
gh release create vX.Y.Z <APK和更新清单等资源> --verify-tag --notes-file <本次发布说明>
```

应用从最新稳定 Release 读取更新清单。下载按已安装 APK 的 ABI 选择，断开后可以继续。安装包经 SHA-256、版本、应用 ID、ABI 和签名验证后交给 Android 安装。现有包的 SHA-256 匹配差分基线时优先使用差分，差分失败时下载完整包。

Fork 可以通过 `-PvlocUpdateRepository=owner/repo` 指定自己的公开更新仓库。
